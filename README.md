# Preeti Patil — Product Management Portfolio

A multi-page portfolio website showcasing product case studies, UX flows, leadership initiatives, and analytical frameworks.

## 🚀 Free Deployment on GitHub Pages

This portfolio is built with zero-build pure semantic HTML5, CSS3, and JavaScript — designed to deploy instantly for free on GitHub Pages.

### Deployment Steps:
1. Create a new GitHub repository named `portfolio`.
2. Push this directory to GitHub:
   ```bash
   git add .
   git commit -m "Initial commit: Preeti Patil portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/portfolio.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** → **Pages**
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**
   - Select branch **main** and folder **/(root)**, then click **Save**.
4. Your site will be live at `https://<your-username>.github.io/portfolio/` within minutes!

- `script.js` — Shared interactions (Screenshot lightbox zoom, reading progress bar, mobile menu)
- `images/` — Extracted screenshot assets and project card previews
- `favicon.svg` — Custom indigo "PP" brand favicon
